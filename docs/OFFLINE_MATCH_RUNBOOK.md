# 离线对局开局 Runbook

Agent 自行进入「离线5V5 / 单人训练」对局的固定步骤。2026-10-20 在 MuMu 模拟器上按用户演示走通（小乔，进入对局 00:16）。

- 环境：MuMu 15，横屏 1920×1080，adb `127.0.0.1:16384`，包名 `com.tencent.tmgp.sgame`
- 参考截图：`docs/assets/offline_match/01~06*.png`

## 前置

```bash
cd D:/work/aiKings/WZRYagnt
./tools/scrcpy/adb.exe connect 127.0.0.1:16384
./tools/scrcpy/adb.exe devices          # 应为 127.0.0.1:16384  device
```

游戏未启动时：

```bash
./tools/scrcpy/adb.exe shell monkey -p com.tencent.tmgp.sgame -c android.intent.category.LAUNCHER 1
```

等主界面出现（右侧竖排图标、底部「开始游戏」）。每一步先截图确认界面，再点下一步：

```bash
./tools/scrcpy/adb.exe exec-out screencap -p > temp/mumu_check.png
```

## 注意与坑

- 不要点设置弹窗中下方的「退出本局」——会判负结束本局。
- 局内高负载下 `adb exec-out screencap` 可能卡住（adbd wedge，历史问题）；采集画面优先走 scrcpy 流，开局阶段截屏没问题。
- 模拟器重启后 adb 需重新 `connect`；端口 16384。
- 主界面若弹活动/公告，先关弹窗再点「离线5V5」。
- 坐标基于 1920×1080；分辨率或 UI 版本变化时按比例缩放，并以当场截图为准。
